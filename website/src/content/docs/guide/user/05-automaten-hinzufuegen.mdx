<Aside type="note">
Dieser Schritt ist nur für Administratoren möglich.
</Aside>

Navigieren Sie zu **Einstellungen → Automaten** und tippen Sie neben rechts neben **Automaten** auf das **+**.

Gehen Sie zum TouchTerminal des AlmaPro, den Sie hinzufügen möchten, und rufen Sie dort das folgende Menü auf:

Rufen Sie am TouchTerminal das folgende Menü auf. Die Ziffern im Bild entsprechen der Reihenfolge der Schritte:

<Image src={AufrufSetupCloud} alt="Menü am TouchTerminal mit den Schritten 1 bis 5" width={600} />

1. Tippen Sie links auf **Einstellungen** (Zahnrad).
1. Tippen Sie in der unteren Leiste auf das Symbol für die **Touch-Einstellungen**.
1. Tippen Sie auf **Zubehör**.
1. Tippen Sie auf **Urban Cloud Service**.
1. Tippen Sie auf **Einstellungen öffnen**.

Das TouchTerminal zeigt die **Urban Cloud Übersicht**. Die rote Anzeige bei **Registrierung am Server** zeigt, dass das Terminal noch nicht registriert ist. Tippen Sie auf das Zahnrad neben dieser Zeile.

<Image src={Registrierung} alt="Urban Cloud Übersicht mit roter Anzeige bei Registrierung am Server" width={450} />

Das TouchTerminal zeigt die **Urban Cloud Registrierung** mit einem QR-Code. Scannen Sie ihn mit der App.

<Image src={RegistrierungQRCode} alt="Urban Cloud Registrierung mit QR-Code am TouchTerminal" width={450} />

Die App meldet **Automat hinzugefügt**.


<Aside type="caution">
Die Synchronisierung kann einige Minuten dauern. Tippen Sie auf das Symbol zum Aktualisieren (↻) und loggen Sie sich gegebenenfalls nach 5&nbsp;Minuten neu ein.
</Aside>

Zurück in der App haben Sie zwei Möglichkeiten:

- **Weitere Automaten vorhanden:** Wiederholen Sie diesen Schritt für jeden weiteren Automaten.
- **Alle Automaten hinzugefügt:** Fahren Sie mit [Schritt 6: Automaten lizenzieren](/guide/user/06-automaten-lizenzieren) fort.
