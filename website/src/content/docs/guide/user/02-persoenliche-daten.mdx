Geben Sie Ihre persönlichen Daten ein:

- Name
- Vorname
- E-Mail-Adresse
- Passwort (wählen Sie ein eigenes Passwort)
- Passwort bestätigen

Aktivieren Sie anschließend die Checkboxen für die **Nutzungsbedingungen** und die **Datenschutzerklärung**. Beide sind erforderlich.

{/* TODO: Screenshot Formular "Konto erstellen" – Grafik ausstehend */}

Tippen Sie auf **Fortsetzen**.

<Aside type="note">
Wurden Sie von einem Administrator eingeladen, geben Sie nur diese persönlichen Daten an. Der Schritt „Firmendaten“ entfällt. Die App meldet, dass Ihr Konto erfolgreich erstellt wurde. Fahren Sie mit [Schritt 4: Einloggen](/guide/user/04-einloggen) fort. Die Schritte 5 bis 7 sind Administratoren vorbehalten.
</Aside>
