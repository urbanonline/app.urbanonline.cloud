Starten Sie die Urban App. Der Startbildschirm ist zugleich der Login.

<Image src={Startbildschirm} alt="Startbildschirm mit Link Registrieren und Button Demo-Modus" width={300} />

- **Sie haben bereits ein Konto:** Loggen Sie sich ein und fahren Sie mit [Schritt 4: Einloggen](/guide/user/04-einloggen) fort.
- **Sie haben noch kein Konto:** Tippen Sie auf den Link **Registrieren** und fahren Sie mit Schritt 2 fort.

## Demo-Modus

Wenn Sie die App zunächst ausprobieren möchten, tippen Sie auf **Demo-Modus testen**.

<Aside type="tip">
Auf älteren Geräten oder Geräten mit kleinem Display müssen Sie nach unten scrollen, um den Button zu sehen.
</Aside>

<Aside type="note">
Für den Demo-Modus und Ihr echtes Konto können Sie dieselbe E-Mail-Adresse verwenden. Der Unterschied liegt im Passwort: Das Passwort für die Demo-Version erhalten Sie per E-Mail. Das Passwort Ihres echten Kontos legen Sie selbst fest.
</Aside>
