<Aside type="note">
Dieser Schritt gilt nur für das Administrator-Konto. Eingeladene Nutzer überspringen ihn.
</Aside>

Geben Sie die Daten Ihres Unternehmens ein:

- Firmenname
- Firmen-E-Mail-Adresse
- Land
- Händler (Auswahl aus der Liste)
- Adresse
- Postleitzahl und Ort
- Vertriebspartner
