Saisissez vos données personnelles :

- Nom
- Prénom
- Adresse e-mail
- Mot de passe (choisissez votre propre mot de passe)
- Confirmer le mot de passe

Cochez ensuite les cases correspondant aux **Conditions d'utilisation** et à la **Politique de confidentialité**. Les deux sont obligatoires.



Appuyez sur **Continuer**.

<Aside type="note">
Si un administrateur vous a invité, saisissez uniquement ces données personnelles. L'étape « Données de l'entreprise » ne vous concerne pas. L'application indique que votre compte a bien été créé. Passez à l'[Étape 4 : Connexion](/fr/guide/user/04-einloggen). Les étapes 5 à 7 sont réservées aux administrateurs.
</Aside>
