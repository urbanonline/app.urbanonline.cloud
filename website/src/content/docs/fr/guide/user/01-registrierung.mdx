Lancez l'application Urban. L'écran d'accueil sert également d'écran de connexion.

<Image src={Startbildschirm} alt="Écran d'accueil avec le lien S'inscrire et le bouton Mode démo" width={300} />

- **Vous avez déjà un compte :** Connectez-vous ➀ et passez à l'[Étape 4 : Connexion](/fr/guide/user/04-einloggen).
- **Vous n'avez pas encore de compte :** Appuyez sur le lien **S'inscrire** ➁ et passez à l'étape 2.

## Mode démo

Si vous souhaitez d'abord essayer l'application, appuyez sur **Tester le mode démo**.

<Aside type="tip">
Sur les appareils plus anciens ou dotés d'un petit écran, vous devez faire défiler vers le bas pour voir le bouton.
</Aside>

<Aside type="note">
Vous pouvez utiliser la même adresse e-mail pour le mode démo et pour votre compte réel. La différence réside dans le mot de passe : vous recevez le mot de passe de la version démo par e-mail. Le mot de passe de votre compte réel, vous le définissez vous-même.
</Aside>
