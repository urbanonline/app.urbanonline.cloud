L'Urban Feed Monitor App est disponible pour les appareils fonctionnant sous <span  class="font-semibold">Android</span> ainsi que pour les <span  class="font-semibold">appareils Apple</span> sous iOS.

* Les appareils sous Android nécessitent <span  class="font-semibold">Android 7.0 ou supérieur</span>.
* Les appareils Apple nécessitent <span class="font-semibold">iOS 15.6</span> ou supérieur.
