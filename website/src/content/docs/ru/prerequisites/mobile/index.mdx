Приложение Urban Feed Monitor App доступно как для устройств под управлением <span  class="font-semibold">Android</span>, так и для <span  class="font-semibold">устройств Apple</span> под управлением iOS.

* Для устройств с Android требуется <span  class="font-semibold">Android версии 7.0 или выше</span>.
* Для устройств Apple требуется <span class="font-semibold">iOS версии 15.6</span> или выше.
