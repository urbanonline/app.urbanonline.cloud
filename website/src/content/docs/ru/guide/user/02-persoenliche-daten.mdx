Введите свои личные данные:

- Фамилия
- Имя
- Адрес электронной почты
- Пароль (придумайте собственный пароль)
- Подтверждение пароля

Затем установите флажки **Условия использования** и **Политика конфиденциальности**. Оба обязательны.



Нажмите **Продолжить**.

<Aside type="note">
Если Вас пригласил администратор, укажите только эти личные данные. Шаг «Данные компании» пропускается. Приложение сообщит, что Ваша учётная запись успешно создана. Перейдите к [Шагу 4: Вход](/ru/guide/user/04-einloggen). Шаги 5–7 предназначены только для администраторов.
</Aside>
