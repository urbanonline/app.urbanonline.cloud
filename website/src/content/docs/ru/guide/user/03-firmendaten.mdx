<Aside type="note">
Этот шаг относится только к учётной записи администратора. Приглашённые пользователи его пропускают.
</Aside>

Введите данные Вашей компании:

- Название компании
- Адрес электронной почты компании
- Страна
- Дилер (выбор из списка)
- Адрес
- Почтовый индекс и город
- Торговый партнёр



Нажмите **Продолжить**, чтобы завершить регистрацию.

Приложение сообщит, что Ваша учётная запись успешно создана. Теперь Вы можете войти.
