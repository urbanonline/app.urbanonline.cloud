Start the Urban app. The start screen is also the login screen.

<Image src={Startbildschirm} alt="Start screen with the Register link and the Demo mode button" width={300} />

- **You already have an account:** Log in ➀ and continue with [Step 4: Logging in](/en/guide/user/04-einloggen).
- **You do not have an account yet:** Tap the **Register** link ➁ and continue with Step 2.

## Demo mode

If you would like to try out the app first, tap **Try demo mode**.

<Aside type="tip">
On older devices or devices with a small display, you need to scroll down to see the button.
</Aside>

<Aside type="note">
You can use the same email address for demo mode and for your real account. The difference is the password: you receive the password for the demo version by email. You set the password for your real account yourself.
</Aside>
