The Urban Feed Monitor App is available for devices running the <span  class="font-semibold">Android operating system</span> as well as for <span  class="font-semibold">Apple devices</span> running iOS.

* Devices running Android require <span  class="font-semibold">Android version 7.0 or higher</span>.
* Apple devices require <span class="font-semibold">iOS version 15.6</span> or higher.
