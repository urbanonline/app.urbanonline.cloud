## Firmware Version Requirements

Firmware version <span class="font-bold">25-04_V09</span> or higher needs to be installed on the Alma Pro for the installation and setup of the Urban Cloud.

## Checking the Firmware Version

To check which firmware version is installed on your Alma Pro feeder:

* Make sure you are on the feeder’s home screen. If needed, tap the top `Home` button <span class="text-2xl">➀</span> <Home width={20} class="inline ml-2 mb-0" /> in the navigation bar on the left side of the screen.
* On the home screen, tap the `Help` button <span class="text-2xl">➁</span> <QuestionMark width={20} align="top" class="inline ml-2 mb-0" alt="Help menu icon" /> in the upper-right corner of the screen.
* The version number of the installed feeder firmware <span class="text-2xl">➂</span> is now displayed to the left of the language selection button.

## Next Steps

* If the firmware version installed on your feeder is lower than 25-04_V09, first perform a firmware update on your feeder.

* If firmware version 25-04_V09 (or higher) is already installed on your machine and provided that all other [requirements](../) are met, you can begin with the [Urban Cloud setup](../../../guide/service/callup-screen).
