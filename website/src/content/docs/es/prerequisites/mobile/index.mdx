La Urban Feed Monitor App está disponible tanto para dispositivos con sistema operativo <span  class="font-semibold">Android</span> como para <span  class="font-semibold">dispositivos Apple</span> con iOS.

* Los dispositivos con Android requieren <span  class="font-semibold">Android 7.0 o superior</span>.
* Los dispositivos Apple requieren <span class="font-semibold">iOS 15.6</span> o superior.
