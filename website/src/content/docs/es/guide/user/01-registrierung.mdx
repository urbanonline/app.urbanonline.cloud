Abre la aplicación Urban. La pantalla de inicio es también la pantalla de inicio de sesión.

<Image src={Startbildschirm} alt="Pantalla de inicio con el enlace Registrarse y el botón Modo demo" width={300} />

- **Ya tienes una cuenta:** Inicia sesión ➀ y continúa con el [Paso 4: Iniciar sesión](/es/guide/user/04-einloggen).
- **Todavía no tienes una cuenta:** Pulsa el enlace **Registrarse** ➁ y continúa con el paso 2.

## Modo demo

Si primero quieres probar la aplicación, pulsa **Probar modo demo**.

<Aside type="tip">
En dispositivos más antiguos o con pantalla pequeña, tienes que desplazarte hacia abajo para ver el botón.
</Aside>

<Aside type="note">
Puedes usar la misma dirección de correo electrónico para el modo demo y para tu cuenta real. La diferencia está en la contraseña: la contraseña de la versión demo la recibes por correo electrónico. La contraseña de tu cuenta real la defines tú.
</Aside>
